The Challenge: Messy Raw Data

Prior to this project, the raw Olist dataset (spanning 9 disparate sources) suffered from significant quality issues, including multiline records and inconsistent schemas, making immediate business analysis impossible.

My Solution

  • Phase 1 Utilized Spark to handle large-scale processing and resolve complex data formatting issues.
  • Phase 2 Leveraged dbt to build robust business logic and implement automated testing.

1. Heavy Lifting with Spark

Deployed PySpark on Databricks to ingest raw data (Bronze) and perform heavy cleaning and standardization to produce a refined Silver Layer.

  • Handling Schema Drift automatically.
  • Resolving multiline CSV parsing issues.

2. Modeling with dbt

Transformed data into a Star Schema optimized for high-performance BI queries.

The Lineage Graph visualizes the clear data flow from Source -> Staging -> Fact/Dim Tables, ensuring full traceability.

3. Automated Docs & Quality

Beyond just processing, the pipeline generates an automated Data Dictionary, empowering Data Analysts to understand metrics without constant dependency on Engineers.
